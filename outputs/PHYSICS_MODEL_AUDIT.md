# Drill-3D-Model 理論整合性の監査

検証日：2026-09-20。対象：ymsh003/Drill-3D-Model、取得時コミット `215b1f2f2b3cdecb89b8acbbf1e5d2e6c66cd128`。本書はモデル・計算実験・教材を対象とする。

## 1. 判定

**幾何配置と慣性テンソルによる静的比較は、仮定を明記すれば有用。一方、独自指標から実フレアの上限・使用率を求める理論は立証されていない。** 実装には軸定義の誤りと、資料に記載された修正の未反映があった。今回それらを修正し、無外力回転と経験的な見た目の補正を分離した。

修正後も、実球の材料密度、完成球の実測RG、レーン摩擦、リリース姿勢のデータは得られていない。したがって「実際のフレア幅・曲がり量・ブレークポイントを正確に予測するモデル」として承認できる段階にはない。理論の整合性、計算の再現性、実験による妥当性確認は別々の評価である。

## 2. 実装と既存資料の不一致

### 2.1 中間RGとPSA軸：修正必須

USBCの定義では、Total Diff = 高RG - 低RG、Intermediate Diff = 高RG - 中間RG。したがって `RG_high = RG_low + Diff`、`RG_mid = RG_high - IntDiff` である。[S2, S3]

元コードは `RG_mid = RG_low + IntDiff` とし、PSA方向を中間軸、その直交方向を高RG軸にしていた。低RG 2.480、Diff 0.052、IntDiff 0.018なら、中間RGは2.514が正しく、元コードの2.498ではない。IntDiffが0の対称球でも縮退する軸の組が逆転していた。資料では修正済みとされていたが、取得した実装には反映されていなかった。

今回、未ドリル・完成球の両方の定義を修正。PINを低RG方向、直交化したPSAを高RG方向とし、中間方向を右手系になるよう構成した。実球ではPINと実測主軸のずれもあり得るため、表面マークは主軸の近似として扱う。

### 2.2 固有軸の並べ替え：修正必須

固有値を昇順に並べ替える際、固有ベクトルの組が左手系になる場合があった。静的テンソルの再構成では符号の影響は消えるが、外積を使うEuler方程式では回転方向を誤る。第3軸の符号を調整し、常に右手系を保証した。入れ替えを必要とする対角行列でも検証した。

### 2.3 描画状態への依存：修正必須

穴の始点計算がグローバルな投影状態を参照し、同じ入力でも呼出経路によって質量特性が変わり得た。穴の始点を渡されたレイアウトの基底から直接計算するよう修正。描画状態を意図的に変えても慣性・重心が一致することを確認した。

### 2.4 除去体積：修正と限界

元コードは表面中心を始点とした完全な円柱＋円すいを全量除去しており、球面の外側にある部分まで引いていた。今回、穴内の平行な積分線と球の交点を求め、球内部だけを積分する方式に変更した。深さ方向は解析積分、断面は半径24×周方向32の中点積分。半径4.3、穴半径0.5、平底深さ1.5インチの体積は、解析値1.166655718立方インチに対して1.166665684。96×96では1.166656341となり、収束を確認した。

ただし「除去部分を球の平均密度とする」仮定は残る。カタログの3つのRGから内部の材料配置は一意に復元できない。密度境界、偏心コア、実ドリル先端形状、インサート・スラグ・接着剤、重なった穴の除去体積の和集合は未対応。干渉する穴の計算値は有効な完成球予測として使わない。材料情報がない部分を推測値で埋めなかった。

## 3. 独自指標の検証

### 3.1 「Performance Differentialと同じ式」は根拠不足

既存資料は `D = sqrt(Total Diff² + Intermediate Diff²)` をRadicalのPerformance Differentialと同一視していた。しかし引用されたResults Plus表にはこの式の明記がない。さらにB行はTotal 0.054、Intermediate 0.028、掲載値0.052であり、この式の計算値約0.06083と一致しない。原表を画像でも確認した。[S5]

原表に誤植がある可能性は排除できないが、だからといって式の正しさが証明されるわけではない。「メーカー公式式」「フレア上限」という解釈は撤回する。Dは同じ単位の2量を合成した未校正の比較値としてのみ残した。Total Diffへの寄与と非対称性の寄与を独立・直交なものとして二乗和にする物理的根拠も別途必要になる。

### 3.2 方向のずれ U は定義できるが、使用率ではない

元の実験データには `effective_flare_diff_in` と `flare_utilization_pct` があったが、取得した実装はこれらを返しておらず、作成過程を同じ版から再現できなかった。今回、次の明示的な診断量を定義した。元の欠落した実装を完全に復元したと主張するものではない。

`U = 2 |u × (Iu)| / (Imax - Imin)`。uは単位回転軸、Iは完成球の重心まわりの慣性テンソル。等方的ならU=0と定義する。Iuは角速度の大きさで割った角運動量に対応する。

Uは0～1に収まる。固有基底でのuの成分の二乗を重みとすると、`|u × Iu|² = u^T I²u - (u^T Iu)²` は固有値の重み付き分散。その分散は固有値範囲の二乗の1/4以下である。これは数学的な正規化の根拠であり、実フレアの割合の根拠ではない。

理想的な軸対称テンソルでは、低RG軸との角度をθとすると `U = |sin(2θ)|`。45°で最大になる山形は、この定義自体から生まれる。山形がメーカーの説明に似ているだけでは、フレア予測の独立検証にならない。

決定的な反例は中間主軸上の回転である。主軸と完全に一致すればU=0だが、中間主軸まわりの回転は微小なずれに対して不安定になり得る。U=0を「安定」「将来もフレアしない」と解釈できない。主軸上の定常回転と、中間主軸への微小摂動の増大をそれぞれテストした。

### 3.3 物理的に意味を限定した代替量

Euler方程式を `a = -I^(-1)(u × Iu)` と書くと、角速度の大きさをΩとしたとき `du/dt = Ω [a - u(u・a)]`。そこで `K = |a - u(u・a)|` を `torque_free_axis_rate_per_spin` として追加した。

Kは「その瞬間の無外力軸方向変化速度を回転速度で割った量」。単位は無次元。微小時間の実際の積分結果との一致を確認した。Uより運動方程式に直接結びつくが、時間積分した軸移動量や実油リング間隔とは異なる。

旧列名はデータ利用者への互換性のため保持した。`flare_utilization_pct` は100U、`effective_flare_diff_in` はD×Uという未校正の比較値であり、JSONの説明にその意味を明記した。新しい解析ではUとKの列を優先する。角度合計を線形変換した `source_timing_guide_pct` は、反応の速さとの定量対応がないため削除した。

## 4. 運動層と油リング

### 4.1 保存するものを取り違えない

無外力の剛体運動では回転エネルギーと空間固定系の角運動量が保存される。角速度の大きさや、角速度方向まわりのRGが厳密に一定とは限らない。[S6]

旧モデルはEuler積分後の軸を初期RG面へ射影し、USBC表から得たフレア幅で制限し、さらに仮想Bowtieまわりに回転させ、グリップ穴から遠ざかる向きを優先していた。これらの表示軸はEuler方程式の解と一般には一致しない。USBCが観察した「おおむね同じRG」は、測定精度・対象条件を伴う観察であり、無外力計算への厳密な拘束条件にはできない。[S4]

今回、これらの軸方向の補正・経験表による上限制限を計算経路から除去。積分された角速度の方向をそのまま用いる。名称も無外力回転の参考モデルに変更した。既存の60 ftは一定速度から換算する観測時間の目安であり、実レーン上の運動予測ではない。入力RPMから数える回転数も目安である。

### 4.2 大円のリングは一般的な接触軌跡ではない

元資料はファーストトラックを常に `u・r = 0` としていた。これはチルト0などの限定条件である。球の姿勢をQ、上向きレーン法線をn、幾何中心基準の接触点をrとすると、理想球の接触点は球固定座標で `r = -R Q^Tn`。一定軸で回る場合も、チルトがあれば `u・r` は一般に0ではなく、小円になる。

したがって、PAPと慣性だけで本物の油リングやBowtie位置は求められない。今回残した軸に垂直な大円は、軸方向を比較する補助図である。`R×軸間角度` も軸差の長さ換算であり、実フレア総幅ではない。油リングを予測するには姿勢の時間積分、並進運動、接触力、摩擦・油膜などを結合する必要がある。

## 5. 計算実験をどう読むか

### 5.1 ゼロ基準587行

PIN-PAP=0ではPINとPAPが一致するため、その2点から線の向きが一意に決まらない。ここでドリル角・VAL角を別々に振る実験は、座標系の退化や符号の検査には使えるが、実用的なレイアウト感度の検証には不適切。角度同士が鏡像になることは、物理的な作用の同一性を証明しない。実験にこの位置づけを明記した。

### 5.2 594条件の全因子比較

ドリル角9水準、PIN-PAP 11水準、VAL角6水準を等しい重みで計算した。分散分解自体は、均衡全因子計画の記述的解析として妥当。独立した解析式のある合成データで、主効果・2因子・3因子の分解も検証した。

修正後の分散比：PAP方向RGはドリル角5.81%、PIN-PAP 92.13%、VAL角は数値誤差程度、相互作用2.06%。新しいKはそれぞれ29.93%、52.35%、13.26%、相互作用4.46%。D×Uの旧比較値は25.57%、56.32%、13.44%、相互作用4.68%となった。

これらは固定球・固定グリップ・選んだ範囲・等重みでの「モデル出力の分散」の内訳である。実投球の因果寄与率でも、別のボールへ転用できる普遍値でもない。旧資料の29.0%・52.7%などを新計算の結果として引用してはいけない。

この条件のD×U平均は3.5インチで最大になった。しかし前述の山形構造を含む定義に依存するので、実フレアの最大値を実証したことにはならない。単回帰R²も直線近似の当てはまりであり、物理モデルが正しい確率ではない。基準値付近が0の指標を任意の下限尺度で割った「正規化変化幅」も、尺度の選択に順位が左右される。

### 5.3 4コア型252行・6銘柄378行

いずれも再計算し、有限値と版情報を確認した。既存カタログの15ポンド値を入力に用いた比較であり、各銘柄の内部CADを復元したわけではない。メーカー値を入力したことは、完成球の実測値や実投球との一致を検証したことにはならない。カタログの最新性の全面再調査は今回の理論監査と別である。

## 6. 検証結果と残る制限

本番実装の関数を使う12項目の物理テストに合格。軸・RG定義、対称球、固有分解、状態独立性、保存則、主軸の反例、Uの解析解、Kの微分検証、除去体積、ピッチ深さ独立性、左右投球の球面幾何、慣性の物理条件を確認した。

5秒の無外力積分では、回転エネルギーの最大相対誤差8.98×10^(-14)、角運動量の大きさの最大相対誤差4.52×10^(-14)。刻みを細かくした解とも比較した。これらは実装の数値整合性の結果であり、実投球の予測誤差ではない。

全1,811行の必須指標が有限値であること、3つの保存済み条件と再計算が1×10^(-12)以内で一致すること、旧ゼロ基準の鏡像誤差1.33×10^(-15)、594条件の分散和・基本整合性を確認した。既存のグリップ幾何8件も通過。ただし既存の `test_static_experiment.mjs` は取得時点から存在しない旧インターフェース要素を要求して失敗する。本監査はその機能の復旧を行っておらず、「リポジトリの全テストが成功」とは報告しない。

PAP方向の慣性は重心を通りPAP方向に平行な軸について計算する。重心移動後に幾何中心を通る直線の慣性とは平行軸の項だけ異なる。コアの見た目やCG刻印から推定した偏心が、動的テンソルへ厳密に反映されるモデルでもない。測定器の定義と照合するときは軸の位置をそろえる必要がある。

## 7. 実測で次に確かめること

最初に同じ球の穴あけ前後の重量、3主RG、主軸位置、穴の径・深さ・ピッチ、追加部材質量を記録する。平均密度近似の誤差を測り、材料モデルの校正を先に行う。1個の球を繰り返し穴あけして独立なレイアウト比較とみなすことは避ける。

次に同じ表面とレーン条件で、球速・RPM・軸ローテーション・軸チルトを測り、投球順を交互化して複数投記録する。油リングの軸位置・間隔と軸履歴を測る。比較対象はD、U、Kなどを事前に決め、校正用と評価用のデータを分け、平均誤差・ばらつき・予測区間を示す。未測定の摩擦を指標の係数へ吸収し、校正データだけで「理論が正しい」と結論しない。

初心者資料では、幾何の定義を断定し、レーン反応の経験則は条件付きで説明した。フレア量とフック量、レイアウト角と穴のピッチ、対称球と非対称球のPSAの違いを明示した。
